# 「阅读的海洋」主视图 · 生成提示词

> **用法**：把下面「一 ~ 五」整块发给 AI，让它生成这个页面。
> **本期数据**：先用页面里的**假数据**，不接真实存储、不联网（第 3 周才换成真实数据）。

---

## 一、页面目标（用户为什么打开）

用户打开这一页，是为了**一眼看清"我的书都到什么程度了"** —— 不用一本本点进去翻。

它要回答三个问题，按重要性排：

1. 我现在**在读**什么？读到哪了？
2. 我**接下来**要读什么？
3. 我**读完**了什么？

所以这一页是**用来看的，不是用来操作的**：打开就能看完。不需要登录、不需要搜索、不需要跳转。

---

## 二、内容结构（页面必须有什么）

### 顶部

- **标题**：「阅读的海洋」
- **一行更新时间**：「数据更新于 2026 年 9 月 29 日 11:30」
  —— 取这份数据里**最新的一次改动时间**（所有书 `updatedAt` 里最大的那个）；假数据里没写的话，就用当前时间。

### 主体：三栏并列，按阅读状态分栏

| 位置 | 栏标题 | 栏里放哪些书 |
| --- | --- | --- |
| 左 | 想读 | `status === 'want'` |
| 中 | 在读 | `status === 'reading'` |
| 右 | 已读 | `status === 'finished'` |

**三栏本身就是分类，所以不要再另加一排筛选按钮。**

- 每栏最多显示 **5 条**；超出时在栏底加一行「还有 N 本」，**不做滚动、不做翻页**
- 每栏内部**按 `updatedAt` 倒序**（最近有动静的排最前）
- 某一栏为空时，显示一行「还没有想读的书」这类占位文字（**不能留一片空白**）

### 每一条（一本书），从左到右

| 位置 | 显示什么 |
| --- | --- |
| 最左 | **序号** `1、2、3…` —— 每栏各自从 1 开始 |
| 中间 | **书名**（大一点）；下面一行小字是**作者** —— 没填作者就显示「未填作者」 |
| 最右 | **进度**：在读 → `38%`；已读 → `已读完`；想读 → `未开始` |

- **封面**：有 `coverUrl` 就显示小图；没有、或者图加载失败 → 显示**书名第一个字**的占位块（**不能显示破图图标**）
- 序号是"看得见的顺序"，不是书的 `id`

### 四种页面状态（本页的重点，一个都不能省）

| 状态 | 什么时候出现 | 必须显示什么 |
| --- | --- | --- |
| **加载中** | 数据还没到 | 一句「正在读取你的书架…」—— **不能**是一片空白，也不能只有一个转圈 |
| **成功** | 数据正常拿到 | 上面那套三栏 |
| **空** | 一本书都没有 | 「书架还是空的」+ 一句引导 —— **不能**一片空白 |
| **错误** | 取数据失败 | 一句**能看懂**的错误提示（把原因带出来）+ 一个「重试」按钮 —— **不能**白屏 |

### 数据从哪来（本期要求）

- 在页面里写一份**假数据**：**5 ~ 10 本书**，三种状态都要有，其中至少一本在读、一本没填作者、一本没有封面
- 读数据时**人为延迟约 0.8 秒** —— 不延迟的话，「加载中」状态根本来不及出现
- 取数**只留一个函数入口**（例如 `fetchBooks()`）—— 第 3 周把它换成真实数据源时，只改这一个函数，别的地方一行不动

## 三、视觉要求（看起来和用起来要怎样）

- **信息层级清楚**：页面标题 > 栏标题 > 书名 > 作者/进度，字号依次变小，一眼能分出主次
- **卡片可扫描**：快速扫过去时，**书名和进度要能被看到** —— 别把关键信息塞进小字、浅灰字里
- **桌面宽度（≥1024px）**：三栏**并排**，**一屏装下**，**不出现横向滚动条**
- **手机宽度（≤480px）**：三栏改为**从上到下堆叠**（想读 → 在读 → 已读），**任何元素都不能被挤出屏幕右边**
- **长书名要换行**，不能撑破卡片、不能被切掉
- **用色克制**：状态靠**文字**区分，不靠大面积色块；同一栏内部颜色统一
- **零外部资源**：不引用任何 CDN 的字体、图标、框架、图片（这台机器在校园网 + 代理环境下，外部资源不可靠）
- 样式写在**单独一个 CSS 文件**里，不写行内样式

---

## 四、限制（不要做什么）

**功能上**

- 不加**登录、注册、账号** —— 本项目是单机自用，没有用户系统
- 不加**支付、会员、付费**
- 不加**社交**：关注、点赞、评论、分享、好友、订阅
- **不显示书籍正文、摘要、章节内容、书评** —— 本项目是个人记录工具，不提供书籍内容
- 不加搜索、排序切换、拖拽、分页、导入导出、深色模式等**没被要求**的功能
- 不写真实网络请求，不引用任何外部 API

**技术上**

- 只用**原生 HTML + CSS + JavaScript**；不引入 React / Vue / Tailwind / jQuery 或任何构建工具
- **不使用 ES Module**（`import` / `export`）—— 这一页要能用**双击 `index.html`** 的方式打开
- **不改动数据里的字段名和取值**：
  - `status` 只有 `'want'` / `'reading'` / `'finished'` 三个值 —— 不要换成中文，也不要改拼写
  - 进度**不单独存字段**，按 `currentPage ÷ totalPages` 实时算（四舍五入到整数）
  - 现有字段名：`id` / `title` / `author` / `coverUrl` / `status` / `totalPages` / `currentPage` / `startedAt` / `finishedAt` / `createdAt` / `updatedAt`
- 不要新建没被要求的文件，也不要顺手去改项目里已有的其他文件

## 五、验证要求（怎么算通过 —— 每条都能亲手做）

请把「好不好看」落到下面这些**能亲手做**的动作上。每条都写清：**怎么做 → 看到什么算过**。

### A. 桌面宽度（窗口拉宽到 ≥1024px）

| # | 怎么做 | 看到什么算过 |
| --- | --- | --- |
| A1 | 打开页面，等加载完 | 三栏**并排**；页面**没有**横向滚动条（窗口底部没有左右滑条） |
| A2 | 数每栏的条数 | 每栏 ≤ 5 条；序号从 1 连续递增，**没有跳号** |
| A3 | 找一本「在读」的书 | 右侧有百分比；**自己按计算器核**：`currentPage ÷ totalPages` 四舍五入，应等于页面上的数字 |
| A4 | **眯起眼睛**扫一遍三栏 | 不看小字也能分清哪栏是在读、哪栏是已读 |
| A5 | 找一本没有封面的书 | 显示的是**书名第一个字**，不是破图图标 |
| A6 | 按 F12 打开 Console | **没有任何红色报错** |

### B. 手机宽度（F12 → 点左上角手机图标；或把窗口拖到 375px 宽）

| # | 怎么做 | 看到什么算过 |
| --- | --- | --- |
| B1 | 缩到 375px 宽 | 三栏变成**从上到下**（想读 → 在读 → 已读），不是三栏挤在一起 |
| B2 | 试着**横向拖一下**页面 | **拖不动** —— 没有横向滚动条，没有任何元素被挤出屏幕右边 |
| B3 | 找书名最长的那本 | 文字**换行了**；卡片没被撑破，右边没有被切掉的内容 |
| B4 | 看「在读」的百分比数字 | 还在卡片里，没被挤出去 |

### C. 四种状态（每条都要**亲眼看到**）

| # | 怎么做 | 看到什么算过 |
| --- | --- | --- |
| C1 | 刷新页面，**眼睛盯住页面** | 有一瞬间显示「正在读取你的书架…」，之后才变成三栏 |
| C2 | 把假数据改成**空数组** `[]`，刷新 | 显示「书架还是空的」这类提示，**不是**一片空白 |
| C3 | 让取数函数**故意抛一个错**，刷新 | 显示错误提示 + 「重试」按钮，**不是**白屏；点「重试」能重新走一遍加载 |
| C4 | 把 C2 / C3 的改动**改回去**，刷新 | 恢复正常三栏 |

### D. 交付时要附上的数字

- 三栏**各自实际的条数**（要真数字，不是"大约"）
- 「在读」那本的百分比，**以及你手算的结果** —— 两个数必须对得上
