Day 2 · 占位页

阅读的海洋 The Sea of Reading

记录读过的每一本书，也记录读它的那段时光。

当前状态

项目骨架已就位，功能尚未开始 —— 这是一个占位页，正式版本将在 Day 7 上线。

你看到这个页面，说明仓库、提交、推送三条链路已经全部打通。 页面本身现在没有交互功能，它的作用是证明「代码能从本机走到 GitHub，也能从 GitHub 变成网页」。

这个项目想做什么

  • 书单管理 —— 把想读的、在读的、读完的分开摆放
  • 阅读进度 —— 记下每次读到哪一页，不用再靠书签猜
  • 读书笔记 —— 摘抄、随想、评分，都留在一处
  • 阅读统计 —— 一个月读了几本、平均多久读完一本

以上都是计划，不是现状。功能会按学习计划逐日补齐，避免贪多。

进度

  • 本地 Git 仓库初始化、忽略规则配置
  • GitHub 远程仓库连接、SSH 推送通道打通
  • 首次提交与推送，页面文件上线
  • Day 7 —— 做出可用的 MVP 页面
  • Day 23 —— 接入数据库配置（.env 届时才会用到）

关于本地运行

这是一个纯静态页面，没有任何依赖，也不需要构建工具。直接双击 index.html 就能在浏览器里打开。

以后如果需要本地起一个服务，在项目目录下执行 npx serve 即可。
